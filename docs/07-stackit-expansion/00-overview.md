# STACKIT Expansion

In this expansion section, we move the local workflow to STACKIT.

## What You Will Build

- STACKIT Kubernetes Engine cluster
- KFP deployment on SKE
- object storage-backed artifacts
- optional GPU node pool
- cleanup workflow

## Why This Matters

The local workflow teaches the concepts. STACKIT shows how the same architecture maps to a sovereign-cloud environment.

## Acceptance Criteria

You are done with this section when:

- the same pipeline can run on STACKIT
- artifacts are stored in cloud object storage
- cleanup steps prevent idle cloud costs
