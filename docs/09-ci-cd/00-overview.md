# CI/CD Expansion

In this expansion section, we automate builds, checks, and pipeline compilation.

## What You Will Build

- image build workflow
- pipeline compilation workflow
- optional pipeline submission workflow
- GitOps-style model promotion concept

## Why This Matters

A reproducible workflow should not depend on manual laptop state. CI/CD moves build and validation steps into repeatable automation.

## Acceptance Criteria

You are done with this section when:

- images are built in CI
- pipeline definitions are compiled in CI
- tests and type checks run automatically
- promotion can be represented as a Git-tracked change
